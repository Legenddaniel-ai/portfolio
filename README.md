# Ayomide Daniel portfolio

Static site: no build step. Open `index.html`, or upload the folder to any static host (Netlify, Vercel, GitHub Pages, cPanel).

- `index.html`: all pages. The home page and the Book a Call page (`#book`) live in this one file.
- `styles.css`: all styling. Colours and theme are CSS variables at the top (`:root`).
- `script.js`: menu, scroll effects, project accordion, contact form, booking requests.
- `assets/portrait.jpg`: your photo (4:5). Replace it with another 4:5 image to change it.

## Settings (top of `script.js`)

- `GITHUB_URL`: add your GitHub profile URL and the GitHub links appear on the page.
- `BOOKING_URL`: add a Calendly or Cal.com link and an "Open booking calendar" button appears on the Book a Call page.
- `SLOTS`: the preferred time options (WAT) on the Book a Call page. Edit them to match your real availability.
- `PURPOSES`: the call purposes people can choose.

## Not included (add when you have them)

Education and work history, real project screenshots, and repository links for the projects.
